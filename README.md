# Abartılı Çay Bekletme Cihazı

## Giriş

Bu proje, insanlık tarihinin en önemli sorunlarından biri olan "çay ne zaman hazır olur?" sorusuna bilimsel ve abartılı bir çözüm getirmektedir. Çay asla hazır olmaz. Ama demlenmeye devam eder. Bu, modern bilimin zaferidir.

## Özellikler

- Sonsuz demleme döngüsü
- Rastgele soğuma olayları
- Abartılı ciddi log mesajları
- Çayın ruhunu anlamaya yönelik derin felsefi çıktılar

## Kullanım

```bash
python cay_beklet.py
```

Çıktıyı dikkatle izleyin. Her satır, çay biliminin bir zaferidir.

## Uyarı

Bu cihazı gerçek çay demlemek için kullanmayın. Çayınız soğur. Ve siz beklemeye devam edersiniz. Bu bir özelliktir, bug değildir.

## Katkıda Bulunma

Pull request açmayın. Çay demlenirken PR açılmaz. Bu kuraldır.
